# 流口水 Skill 🤤

**English name: Halazi Skill**

**把烧脑的 AI 项目，变成流着哈喇子也能做的选择题。**

不懂产品、不懂代码，也能借助 Agent（替你执行任务的 AI 助手）把中大型 AI 项目一步步推到结果。

> **当前状态：共同设计中，尚不可安装。** 这个仓库先公开已经确认的产品方向；Codex 原生 Skill、通用复制口令和真实示例完成验收后再开放使用。

## 它要解决什么

普通人使用 AI 推复杂项目时，经常被迫回答这些烧脑题：

- 需求应该怎样写？
- 应该用哪个工具或 Skill？
- 技术路线应该怎么选？
- 现在到底做到哪了？
- 测试通过，是否代表真的交付了？

流口水 Skill 不把这些题重新扔给用户。Agent 先查事实、比较方案和判断风险，再把真正需要用户决定的部分变成少量选择题。

## 已确认的原则

1. **先给推荐，再给选项。** 每道选择题都说明推荐、理由、好处和代价。
2. **用户不负责挑 Skill。** Agent 自动选择需要的能力与工具，并用一句人话解释正在做什么。
3. **能安全推进就直接推进。** 只有结果取舍、付费、账号、隐私、高风险操作和重大路线变化才交给用户决定。
4. **不拿动作冒充结果。** 文档、代码和测试不能替代真实用户结果。
5. **普通人是第一用户。** 不要求先学习项目管理、产品或技术术语。

## 首版计划

- **Codex 原生 Skill：** 长期使用的可安装入口。
- **通用复制口令：** 不安装也能在其他 AI 中体验核心协作方式。
- **能力与工具路由：** 把需求访谈、调研、复用、诊断、复核和验收放到正确阶段。
- **一个完整示例：** 从一句大白话目标，到第一道选择题，再到真实验收。

## 当前不宣称

- 尚未提供可安装版本。
- 尚未证明兼容所有 Agent。
- 尚未证明对所有项目都有效。
- 尚未选择开源许可证。

这个仓库与现有“苦难行军”仓库并存：前者面向普通用户做产品化，后者保留真实项目中提炼组织能力的过程与证据。
